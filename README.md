# FRAME · 前端图谱

中文前端技术、视觉语言与 Three.js 交互展示库。

公开网址：https://gmate-sg.github.io/temp-showcase/

## 内容与功能

- 150 个条目：116 项技术、34 项视觉风格，分为十个门类。
- 搜索中文、标准英文名称和关键词；支持分类、技术/风格筛选、详情与本机收藏。
- Three.js r186.1 实时示例：参数曲面、3,200 点粒子星环、169 立方体实例矩阵。支持旋转、缩放、材质、暂停、速度和键盘视角。
- 中文解释、应用场景与直接参考链接。CSS 小图是原创抽象样式标本；目录中的技术条目不等于全部都在本页实际实现。
- 尊重系统减少动态效果设置；3D 按可见性渲染，限制像素比；WebGL 2 不可用时显示提示并保留目录功能。

## 修改

`index.html`：页面结构与固定文案；`styles.css`：样式；`app.js`：检索、详情和收藏；`catalog.json`：条目数据。

`src/scene.js` 是可编辑 Three.js 源码，`graphics.js` 是包含依赖的浏览器构建文件。Three.js 与 OrbitControls 遵循 MIT 许可，见 `vendor/LICENSE`。

只修改条目和页面样式时无需构建；修改 3D 源码后执行：

```sh
npm install
npm run build:3d
```

本地预览需要 HTTP 服务，不能直接双击 HTML 使用模块与 fetch：

```sh
python -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。已发布网站不需要安装任何工具。

GitHub Pages 从 `main` 分支的根目录发布；资源均使用相对路径，适合仓库子路径。`noindex` 降低索引意图，但站点是公开的。收藏只存在当前浏览器，不在电脑之间同步。

## 内容边界

分类是可扩展的认知框架，前端生态持续变化，不能将条目数量理解为穷尽所有技术。支持标签表示实际采用方式，不是完整浏览器版本矩阵；实验能力需要逐项查阅最新文档与环境。
