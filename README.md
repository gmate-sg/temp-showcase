# FRAME · 网站组件与交互样式索引

黑、白、金、红的静态网站，聚焦导航、布局、按钮、表单、卡片、反馈、浮层、媒体、交互和 Three.js 视觉。

## 内容与演示
- catalog.json 是可扩展的组件样式索引，包含中文名称、英文术语、分类、用途与操作提示。
- src/demos.js 和 demos.css 提供真实可操作的界面样式详情，不依赖外部服务，不提交表单资料。
- src/scene.js 提供实时 Three.js 入场、首页、展厅和详情画面，graphics.js 是可直接部署的本地依赖包。
- 每次加载页面都播放五秒入场动画，最后0.7秒平滑衔接主界面。没有跳过、重播、场景暂停按钮。
- 场景保持动态，支持拖动与调整速度/光强。减少动态效果设置会采用更平缓的视觉，但入场仍持续五秒。
- 收藏只保存在当前浏览器，不会跨电脑同步；所有电脑打开同一网址可浏览相同的站点内容。

## 本地运行
使用静态 HTTP 服务打开本文件夹。例如在本目录运行：

    npx --yes http-server . -p 8173

在浏览器访问 http://127.0.0.1:8173/ 。直接双击 index.html 的 file URL 不能可靠加载模块与索引。

## 编辑与构建
普通内容修改不需要构建。修改 Three.js 源码后，在本目录执行：

    npm install
    npm run build:3d

依赖固定为 Three.js0.186.1、esbuild0.28.2。生产页面不需要外部CDN或服务端。Three.js MIT许可保留在 vendor/LICENSE。

## 发布
本目录内容部署到 GitHub Pages main分支根目录。使用相对路径，支持仓库子目录网址。

## 边界
本网站是交互样式展示和选型参考。示例数据、登录、付款和上传均为本地演示，不产生真实业务操作。不同条目有针对性的效果变体，基础交互逻辑共用。实际项目仍需结合业务、设备与无障碍要求调整。
