# NEBULA · 星云科技艺术馆

以 3D 银河组织 8 个技术星系、16 个子星系和 32 个可交互实验。黑白金红基调，紫蓝点缀。每次加载从首个 Three.js 渲染帧开始强制播放五秒开场，随后平滑进入银河。

## 浏览与操作

- 拖拽旋转、滚轮或双指缩放；点击恒星进入分类，点击雕塑进入技术实验。
- 顶部搜索支持名称、英文和关键词，也可搜索“随机”“漫游”“流星”“引力波”“声音”“保存”。
- 空白区域按住形成引力扰动；双击释放波纹。键盘 W 引力波、M 流星、X 结构展开、R 复位镜头、空格随机探索、Esc 返回上一层、/ 搜索。
- 行星面板提供实验参数和动作、模型展开/跃动/共振、关联探索、来源、分享坐标和保存当前构图。访问记录保存在当前浏览器。
- 声场默认关闭，仅在主动选择声音指令后开启。

## 本地运行与修改

使用任意静态 HTTP 服务运行目录，例如 Python `python -m http.server 8173`，然后访问 http://localhost:8173/ 。请通过 HTTP 打开；浏览器会限制 file 协议下的模块和目录数据读取。

修改 `catalog.json` 的名称、说明、分类、来源和参数。修改 `src/experiments.js` 维护实际计算与原理演示；`src/artifacts.js` 维护三维雕塑；`src/scene.js` 维护银河、镜头和空间交互。实验模块直接加载，三维源文件修改后需要构建：

```sh
npm install
npm run build:3d
```

Three.js 0.186.1 与 esbuild 0.28.2 固定版本。预构建的 `graphics.js` 已包含依赖，发布后访问无需安装。MIT 许可在 `vendor/LICENSE`。

## 内容边界

此版本是技术艺术展示与浏览器实验，包含实际计算、原理模拟、研究可视化三种标记。人工智能、世界模型、蛋白结构等展示采用本地可解释模型，不连接大型模型推理服务，也不代表研究系统的完整复现。每颗行星列出原始研究或官方来源；收录日期为 2026-10-01，并非全部领域的排名。

GitHub Pages 根目录静态发布，无密钥、账户、付费接口或后端。编辑内容后将目录同步到仓库主分支即可更新。分享链接携带星云种子与当前行星坐标。
